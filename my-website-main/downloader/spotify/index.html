03 / FAQ

Pertanyaan umum.

Apakah ini gratis?

Ya, sepenuhnya gratis dan tidak ada batas jumlah download.

Bisa download playlist penuh?

Saat ini paling stabil untuk link track tunggal. Dukungan playlist tergantung pada API yang digunakan.

Kenapa link saya gagal diproses?

Pastikan link yang di-paste adalah link Spotify yang valid (open.spotify.com atau spotify.link) dan track-nya masih tersedia.

Apakah data saya disimpan?

Tidak. Link hanya dipakai sekali untuk mengambil file, tidak ada history yang disimpan di server.
